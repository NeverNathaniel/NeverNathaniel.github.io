# nathanSol — NeverNathaniel.github.io

Personal site for Nathan Sol. A collection of things built, tools collected, and interests.

## Pages

| Route | Description |
|---|---|
| `index.html` | Home / intro |
| `useful.html` | Collected tools, reading, and reference diagrams |
| `made.html` | Built projects |
| `likes.html` | Music, media, and interests |

## Stack

Plain HTML and CSS, no build step. Uses [IBM Plex Mono](https://fonts.google.com/specimen/IBM+Plex+Mono) via Google Fonts, jQuery 3.7.1, and a small custom typewriter plugin (`js/typewrite.js`).

Deployed via GitHub Pages from the `main` branch.
